# Legacy Component Archive

These components (`About.tsx`, `Capabilities.tsx`, `QualityProcess.tsx`, `ExportExecution.tsx`) were previously created during early design explorations.
They were superseded by the consolidated, modern `WhyITEC.tsx`, `Certifications.tsx`, and `Industries.tsx` components to eliminate content redundancy, streamline user conversion, and reduce bundle size.

Preserved here for reference if separate dedicated subpages (e.g. `/about`, `/capabilities`, `/quality`, `/logistics`) are introduced in the future.
